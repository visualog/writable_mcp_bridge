## UI 표면
- 플러그인 헤더 아래에 웰컴 메시지가 있고, 사용 가능한 작업을 짧게 설명합니다.
- 시작 화면에는 제안 프롬프트 chips가 노출됩니다.
- 헤더에는 `+ New Chat` 성격의 대화 초기화 액션이 있습니다.
- 입력창 위에는 메시지 제한 또는 업그레이드 성격의 상태 바가 있습니다.
- 결과 이후에 후속 액션을 바로 누를 수 있는 흐름이 보입니다.

## 작업 흐름
- 사용자는 자연어 프롬프트로 생성, 변형, 정리, 참조 작업을 요청할 수 있습니다.
- 선택된 요소를 기반으로 variant 생성이나 레이아웃 정리 같은 작업을 유도하는 제안이 보입니다.
- 작업 중에는 채팅 답변만이 아니라 실행 과정을 보여주는 로그성 표시가 존재합니다.
- 완료 후에는 무엇이 만들어졌는지 또는 추가되었는지 요약하는 결과 설명이 보입니다.

## 관찰된 기능 범주
- 새 컴포넌트 생성
- 기존 요소의 variation 생성
- 레이아웃 정리
- 외부 스타일 참조
- 디자인을 코드 또는 별도 코드 환경으로 넘기는 흐름

## 디자인 시스템 관련 신호
- 디자인 시스템 사용 여부를 메인 흐름에서 드러내는 요소가 보였습니다.
- 컴포넌트, 변수, auto layout, variants 같은 Figma 구조를 다루는 사용 예시가 반복됩니다.

## 실행 흔적과 콘솔 힌트
- 실제 사용 중 `Read from ...`, `Created Figma node` 같은 로그가 관찰되었습니다.
- 실행 구조에서 디자인 시스템 카탈로그, 중간 모델 추출, node 생성 흐름을 시사하는 문자열이 관찰되었습니다.

## 제품 성격
- 표면상 채팅 UI를 가지지만, 사용 경험은 일반 메신저보다 작업 콘솔에 가깝습니다.
- 모델과 대화하는 경험보다 현재 무엇을 읽고 만들고 바꾸는지가 더 앞에 나옵니다.
